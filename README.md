# NEXORA

## AI-Powered Career Intelligence Platform

Resume Analysis • ATS Optimization • Job Matching • Career Growth

---

### Overview

**NEXORA** is an advanced AI-powered career intelligence platform designed to transform uploaded resumes into actionable career insights. From parsing skills and calculating ATS compatibility to delivering live job matching and step-by-step career development roadmaps, NEXORA gives candidates a strategic edge.

---

### Key Features

1. **📊 Dashboard**: Executive summary metrics including Overall Score, ATS Compatibility, Resume Quality, Skill Match, and ML Similarity.
2. **🎯 ATS Analysis**: Deep resume keyword evaluation, formatting feedback, and priority optimization suggestions.
3. **🧠 Skill Gap Analysis**: Candidate-specific skill gap detection categorized into High Priority, Medium Priority, and Nice to Have tiers.
4. **🚀 Career Roadmap**: Personalized 4-phase development plan featuring portfolio project recommendations, readiness scoring, and employer market demand analysis.
5. **🤖 AI Review**: Comprehensive evaluation of resume strengths, weaknesses, impact score, and strategic career growth advice.
6. **🎤 Interview Preparation**: Customized technical and behavioral interview questions with STAR-method answer guidance.
7. **✍️ Resume Rewrite**: Intelligent bullet point rewriting and section optimization.
8. **👤 Profile**: Structural overview of candidate contact information, career level, detected skills, and resume sections.
9. **💼 Job Vacancies**: Real-time Adzuna API integration matching candidate profiles against live opportunities across India.

---

### Quick Start

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the NEXORA application:
   ```bash
   streamlit run app.py
   ```

3. Open `http://localhost:8501` in your browser.
